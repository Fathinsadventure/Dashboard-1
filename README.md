An interactive Power BI dashboard designed to explore sales performance across products, categories, customers, countries, and time.

**Project overview**
This project turns order and customer data into a visual overview that helps users explore key sales patterns and compare performance across different dimensions.

**Dashboard features**
- KPI cards for a high-level snapshot of sales, orders, and customers.
- Sales by product to identify products contributing most to sales.
- Sales by product category to compare category performance.
- Monthly sales trend to explore how sales change over time.
- Interactive filters for country, product category, and order date.

**Tools used**
- Microsoft Power BI
- Data modelling and visual analytics
- Interactive slicers and KPI cards
- Bar, doughnut, and line charts

**Questions this dashboard can help explore**
- Which products generate the highest sales?
- Which product categories contribute most to overall sales?
- How do sales change from month to month?
- How does performance vary by country?
- How do the results change when filtering by date or category?

**How to use**
1. Download the .pbix file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Use the country, product category, and order date slicers to filter the report.
4. Compare the KPI cards and charts to explore the filtered results.

**Project purpose**
This is a portfolio project created to practise presenting data in a clear, interactive, and business-focused way. It demonstrates the use of Power BI visuals and filters to make sales data easier to explore.
